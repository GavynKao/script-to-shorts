# 設計決策

## 目標

輸入一段約 2 分鐘的故事劇本，產生 9:16 直式短影音。
最終使用者不會寫程式，但熟悉 Adobe Premiere。

## 已確定的需求

| 項目 | 決定 |
|---|---|
| 畫面來源 | AI 生圖 + Ken Burns 鏡頭推拉（方案 A） |
| 預算取向 | 效果優先 |
| 影片類型 | 約 2 分鐘的故事旁白，有固定角色跨多個鏡頭 |
| 語言 | 台灣國語配音 + 繁體中文字幕 |
| 平台 | Windows 優先 |
| 剪輯軟體 | Premiere Pro 26.3（支援 UXP） |
| 使用介面 | Claude Desktop + MCP，用對話操作 |
| API 金鑰 | 分配方式之後再細分 |

## 架構：兩個 MCP 伺服器

```
Claude Desktop（使用者用中文下指令）
 ├─ MCP ①  script-to-shorts（本 repo，Python）
 │    保存分鏡、角色定裝、生圖、配音、字幕 → 專案素材資料夾
 └─ MCP ②  Premiere 控制（UXP 面板）
      建 9:16 序列、匯入素材、排時間軸、鏡頭推拉關鍵影格、字幕、配樂、輸出
```

- 拆分鏡由 Claude Desktop 本身完成，MCP ① 不需要 Anthropic API 金鑰。
- MCP ② 先實測現有開源專案（例如 leancoderkavy/premiere-pro-mcp）；
  不穩或有安全疑慮則自寫精簡 UXP 面板，只做需要的約 10 個操作。
- 保留 XML 時間軸匯出作為備案，不依賴 Premiere 版本或 MCP。
- 專案資料夾預設在 `文件\ScriptToShorts\<專案代號>`，剪輯師可直接找到素材。

## 流程

```
劇本
 → ① 拆分鏡（Claude）：角色表 + 約 20–30 個鏡頭（旁白 / 畫面描述 / 鏡頭運動）
 → [人工審核分鏡表，可修改、可單獨重生]
 → ② 角色定裝照 → 各鏡頭生圖（以參考圖維持角色一致性）
 → ③ 配音（TTS），以實際音長決定鏡頭長度
 → ④ 字幕（依配音時間點，繁體）
 → ⑤ 合成：Ken Burns 片段 + 配音 + 字幕 + 背景音樂 → MP4
 → ⑥ Premiere 素材包：片段、音檔、SRT、XML 時間軸
```

2 分鐘旁白約 480–520 字（每秒約 4 字），切成 20–30 個鏡頭，每鏡頭 4–6 秒。

## 關鍵風險

- **角色一致性**：故事類最大挑戰。做法：先產生角色定裝照，後續每個鏡頭帶參考圖生成；
  生圖模型需實測比較。
- **成本**：每支影片約 25 張圖 + 2 分鐘 TTS + 重生次數，需在實測後估算。
